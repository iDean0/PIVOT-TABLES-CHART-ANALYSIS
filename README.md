# Pivot Tables & Charts Analysis — Sales Performance

## Project Overview
This project analyzed a full year of sales data (**₦4,542,266,824** in total revenue) using Excel **Pivot Tables** and **Pivot Charts** to uncover performance patterns across region, product line, and time — without writing a single formula, as part of the NGC Intelligence Hub Exhibition.

## Key Insights

### Regional Performance Is Balanced
| Region | Total Sales |
|---|---|
| West | ₦1,210,190,542 |
| North | ₦1,139,936,232 |
| South | ₦1,116,268,465 |
| East | ₦1,075,871,585 |

The gap between the top and bottom region is narrow, showing consistent demand across markets rather than one region carrying the business.

### Product Mix Has No Weak Link
| Product | Total Sales |
|---|---|
| Printer | ₦825,253,418 |
| Monitor | ₦796,775,820 |
| Laptop | ₦749,668,352 |
| Phone | ₦737,859,020 |
| Tablet | ₦723,283,935 |
| Keyboard | ₦709,426,279 |

Sales are spread fairly evenly across all six product lines rather than relying on a single hero product.

### Clear Seasonal Trend
- **Peak:** March — ₦435,596,905
- **Low:** May — ₦352,844,351
- **Notable upticks:** August (₦400,634,523) and December (₦391,619,990), likely tied to seasonal buying cycles

## Takeaway
This project was a strong reminder of how powerful Pivot Tables and Pivot Charts are for turning thousands of transactional records into decision-ready insights in minutes — clean, structured analysis with zero manual formula work.
